Building StackGraph

A browser-only tool that turns a docker-compose.yml into an interactive service graph. This page explains how it works, why it is built the way it is, and what went wrong along the way.

  • Angular 21
  • TypeScript (strict)
  • Signals + RxJS
  • ELK.js
  • Docker
  • GitHub Actions
  • Nothing leaves the browser. No backend, no upload, no analytics.
  • Four layers, one direction. Parser, mapping and geometry are plain functions, tested without Angular or a DOM.
  • Built to be accessible. A text view of the whole stack, full keyboard control and deliberate focus handling.
